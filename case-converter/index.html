FAQ

Questions, answered

Is Case Converter free?

Yes. It is free and open source under the MIT License, and the code is on GitHub.

Does it send my text anywhere?

No. The app works fully offline and your text stays on your computer.

Which systems are supported?

Windows 10 and 11 (64-bit) today. It is built with Tauri, so you can also build it for other platforms from the source.

Does it work with Vietnamese text?

Yes. Letters with accents are kept intact, and you can remove diacritics, create URL slugs and sort lines with Vietnamese rules.

How do I build it myself?

Clone the repository, then run npm install, npm run dev to try it and npm run build to create the installer.
