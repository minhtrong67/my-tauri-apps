Features

Everything you use, none of the clutter

The parts of File Explorer people use every day, rebuilt with a clean Material 3 interface.

Tabs & navigation

Folder tabs, breadcrumbs with sub-folder jump, folder tree, back/forward history and mouse side buttons.

Flexible views

Details with resizable columns, small to large icons with thumbnails, grouping, filters and a preview pane.

Safe file operations

Copy, move and rename with conflict dialog, progress with cancel, Recycle Bin delete and undo.

Archives

Extract and compress ZIP / RAR using WinRAR or 7-Zip when installed, with a built-in ZIP fallback.

Instant search

Filter as you type, press Enter to search every sub-folder in the current location.

Themes & fonts

Light, dark or system mode, any Material color and popular fonts – all changed live.

English & Tiếng Việt

The language of your device is detected automatically and can be switched at any time.

Light & fast

Rust backend with the system WebView – quick start, low memory, smooth animations.

Dual pane & tags

Two folders side by side with drag & drop, colour tags and stars, plus a folder layout remembered per folder.

Command palette

Press Ctrl+K to jump to any folder, file or command. Advanced search with regex, type, size and date filters.

Duplicates & disk map

Find identical files and see what fills your disk with an interactive treemap.

Live & preview

The list refreshes by itself when files change. Press Space to preview images, video, PDF, Markdown and text.

Make it yours

Your colors. Your font. Your window.

Pick any Material color and the whole interface follows – try it on this page. Choose whether the window remembers its size or always opens maximized.

FAQ

Questions & answers

Is Material File really free?

Yes. It is open source under the MIT License – free to use, study, change and share.

Which systems are supported?

Windows 10 and 11 are the target. Parts of the code are cross-platform (Tauri), but features such as WinRAR integration and the mouse side buttons are Windows specific.

Does it replace File Explorer?

It is an alternative that focuses on everyday tasks. You can always jump back with “Show in File Explorer”.

Can I change the language, colors and font?

Yes – open Settings (Ctrl+,). English and Tiếng Việt are available, the device language is detected on first launch, and every Material color and popular fonts can be applied instantly.
