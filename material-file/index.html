Features

Everything Explorer does. And a lot more.

Quick access, drives, tabs and details view – plus the tools you wish Windows had.

Command palette

Press Ctrl+K to jump to any folder, file or command in a heartbeat. Advanced search adds regex, type, size and date filters.

Dual pane & tabs

Two folders side by side, each with its own tabs. Drag files between them or in from Explorer.

Colour tags

Star, colour and filter what matters. Rename the tags to fit your workflow.

Disk usage map

See what fills your drive with an interactive treemap, then dive into any folder.

Duplicate finder

Finds identical files by size and content, then lets you clear the extras safely to the Recycle Bin.

Your colours, your fonts

19 Material colours or any custom colour, light / dark / system, Roboto and four more bundled fonts, three text sizes, English and Tiếng Việt.

Quick look

Press Space to preview images, video, PDF, Markdown and text without leaving the folder.

Always up to date

The list refreshes itself when files change, and thumbnails are cached for instant scrolling.

Light & fast

A Rust core with the system WebView: quick to start, easy on memory, smooth with huge folders.

Make it yours

One colour. A whole design.

Pick a colour and watch every surface, button and shadow of this page – and of the app – follow. Material 3 builds the full palette for light and dark automatically.

FAQ

Good to know.

Yes. It is open source under the MIT licence – no ads, no accounts and no paid tier.

Windows 10 and 11 (64-bit) with WebView2, which is built into Windows 11. Some features, such as the Recycle Bin shortcut and the Explorer context menu, are Windows-only.

The installer is not code-signed yet, so SmartScreen shows a warning. Choose “More info” and then “Run anyway”. You can also build the app yourself from the source code.

No tracking or analytics. The only network request is an optional once-a-day check for a new release on GitHub, which you can switch off in Settings.

Install Node.js and Rust, then run “npm install”, “npm run dev” and “npm run build”. The README explains every step.
