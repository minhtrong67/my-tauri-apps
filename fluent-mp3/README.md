# Fluent MP3

**Search or paste a link — get a tagged MP3 from YouTube, TikTok and Spotify.**
A free, open-source desktop app built with Tauri, React and **Microsoft Fluent Design**.

## Introduction

Fluent MP3 turns links (or just a song name) into MP3 files with cover art, title, artist, album and year embedded. It wraps [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [ffmpeg](https://ffmpeg.org) in an interface that looks and feels like a native Windows 11 app: Segoe UI Variable, a NavigationView pane, WinUI-style controls, InfoBars, content dialogs and Windows accent colours.

## Fluent Design

- **Window material (Settings → Appearance)** — choose **Mica** (default), **Acrylic** or **Mica Alt**. The material is applied to the real window by Windows (DWM), so the title bar and navigation pane sit directly on it while the content area is a translucent "layer".
  - Mica / Mica Alt need Windows 11. On Windows 10 or when the system refuses, the app falls back to a solid background automatically (and says so in Settings).
  - Acrylic may feel slightly slower while dragging the window — that is a Windows limitation.
- **Accent colour** — 16 Windows accent colours + custom colour; light/dark/system themes use the Windows rules (Dark 1 / Light 2 fills) with automatic text contrast.
- **Fluent icon, controls and motion** — Fluent System Icons, 4 px / 8 px corner radii, bottom-stroke controls, accent focus underline, ToggleSwitch, ComboBox flyouts, ProgressBar / ProgressRing, entrance animations (respects *reduce motion*).
- **Responsive navigation** — the pane collapses to icons on narrow windows or with the menu button.
- **App icon** — a Windows 11 style tile (blue gradient, light edge, soft shadow) with a music note and a download badge; generated by `scripts/generate-icons.py` (app, installer, uninstaller, NSIS images).

## Features

- **Three sources** — YouTube, TikTok and Spotify tracks (Spotify is matched to the best audio on YouTube and tagged from Spotify's metadata). Many links at once.
- **Search by name** — type a song title, pick a result.
- **Playlists** — open a playlist, tick the tracks, queue them.
- **Edit tags** before downloading (title, artist, album, year).
- **Smart queue** — parallel downloads (1–4), speed limit, automatic retries on HTTP 403, live progress, stop all, **taskbar progress** on Windows.
- **History** — grouped by day, search, play, show in folder, download again, delete file.
- **File naming** — four templates, optional per-artist folders, duplicate policy (keep both / skip / replace).
- **Quality** — best or 320 / 256 / 192 / 128 kbps, optional square cover crop.
- **Network** — browser cookies (for "sign in" errors) and proxy.
- **Safe** — yt-dlp / ffmpeg / Deno downloads are verified with SHA-256, strict CSP, single instance.
- **Stays current** — warns when yt-dlp is outdated and updates it in one click; desktop notifications.
- **Make it yours** — light / dark / system, accent colour, 3 fonts (Segoe UI Variable, Inter, Be Vietnam Pro), 3 text sizes, English & Vietnamese, window mode (remember size / always maximised).
- **Faster workflow** — drag & drop links onto the window, clipboard link suggestions, keyboard shortcuts (`Ctrl+K`, `Ctrl+V`, `Ctrl+1/2/3`, `?`), undo when removing items, queue filters.
- **Upgrade friendly** — tools (yt-dlp, ffmpeg, Deno) and window options from the previous *MP3 Downloader* are migrated automatically.

## Installation

Build the installer (see below) and run `Fluent MP3_<version>_x64-setup.exe` (Windows 10/11, 64-bit). If SmartScreen warns, choose **More info → Run anyway** (the installer is not code-signed). On first launch the app offers to download **yt-dlp**, **ffmpeg** and (recommended) **Deno** for you.

macOS / Linux: build from source and install `yt-dlp` and `ffmpeg` yourself. Mica / Acrylic are Windows-only; other systems use the solid Fluent theme.

## Tech stack

| Layer | Technology |
|---|---|
| Shell | Tauri 2 (Rust) + plugins: dialog, opener, notification, single-instance; `window-vibrancy` for Mica / Acrylic / Mica Alt |
| UI | React 18, TypeScript, Vite 5, Tailwind CSS 3 |
| Design | Microsoft Fluent Design 2 (WinUI 3 tokens), Segoe UI Variable |
| Icons | [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) (`@fluentui/react-icons`) |
| State | Zustand (persisted settings & history) |
| Engines | yt-dlp, ffmpeg, Deno (optional) |

## Development

Requirements: [Node.js 18+](https://nodejs.org), [Rust](https://rustup.rs) and the [Tauri prerequisites](https://tauri.app/start/prerequisites/).

This project lives in a **Cargo workspace** (the root `Cargo.toml` has `members = ["*/src-tauri"]`), so every Tauri project in the folder shares one `target/` cache.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The installer is written to the workspace's shared `target/release/bundle/nsis/` folder.

Regenerate every icon with `pip install pillow numpy && python scripts/generate-icons.py`.

## Project structure

```
fluent-mp3/
├─ assets/                 # README icon
├─ scripts/generate-icons.py
├─ app/                    # Vite root of the desktop UI
│  ├─ index.html
│  ├─ public/
│  └─ src/
│     ├─ components/       # Fluent controls (Button, Select, Overlay, InfoBar…) + feature components
│     ├─ layout/           # TitleBar, NavPane
│     ├─ pages/            # Download, History, Settings
│     └─ lib/              # theme (accent), effect (Mica/Acrylic/Mica Alt), i18n, stores, queue, tools
└─ src-tauri/              # Rust backend, config, capabilities, icons
```
