Write like Word, move like Material.

A fast, lightweight desktop word processor with a Word-style ribbon, paged print layout and real .docx support — wrapped in a modern Material Design 3 interface.

Download for Windows GitHub

Windows 10/11 · macOS and Linux builds from source

Everything you expect from a word processor

Familiar tools, a clean look and smooth motion — without the bloat.

Word-style ribbon

Home, Insert, Design, Layout, References, Review and View tabs, plus contextual Table and Picture tabs.

Real .docx support

Open and save Word files with styles, lists, tables, pictures, headers, footers and page setup preserved.

Pages & tables

Paginated print layout, 7 paper sizes, table of contents, merge/split cells and 8 table styles.

Pictures

Insert, paste or drag in images; resize, rotate, flip and wrap text around them.

Your colors

Light, dark or system theme with Material colors and a custom accent that recolors the whole app.

English & Tiếng Việt

Detects your device language automatically and can be switched at any time.

Window options

Remember the window size you chose, or always open maximized — your call.

Safe by design

Auto-recover copy of unsaved work, unsaved-changes prompts and atomic file saving.

Light & fast

Built with Tauri 2 and Rust, so it starts quickly and stays small.

See it in action

Light and dark themes, tables, settings and the File menu.
