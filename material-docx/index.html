Features

Everything a document needs. Nothing it doesn’t.

The tools you reach for every day, redesigned with bigger shapes, calmer colour and motion that feels alive.

A ribbon you already know

Home, Insert, Design, Layout, References, Review and View — with styles, find & replace, formatting painter, page setup, headers & footers and a table of contents.

Ctrl+BCtrl+FCtrl+ZCtrl+SCtrl+P

Real .docx

Open and save genuine Word files — headings, lists, tables, pictures, headers and footers. Comments and footnotes are kept too.

True page layout

Paged view with margins, orientation, paper sizes and a ruler. Export PDF from the print dialog.

Tables & pictures

Table styles, merge and split cells, shading, borders, resizable pictures with text wrapping.

Your colour, everywhere

Light, dark or system, with an accent palette generated from any colour you pick.

Opens what you have

.docx, .docm, .dotx, .odt, .rtf, .html, .md, .csv, .tsv and plain text — drop a file on the window and go.

English & Tiếng Việt

Switch languages instantly. Five bundled interface fonts, three text sizes, document tabs and window-size memory.

File types

Open almost anything.

Material Docx reads the formats you meet every day and saves clean .docx, .html or .txt files.
