# Download folder

Put the Windows setup file here (for example `Material Docx_2.0.0_x64-setup.exe`) and rename it to:

    Material-Docx-Setup.exe

The landing page (`../index.html`) links to `download/Material-Docx-Setup.exe`.
Installers are produced by `npm run build` in `../../target/release/bundle/nsis/`.
