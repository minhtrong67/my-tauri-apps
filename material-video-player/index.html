Material Video Player
Features

Everything in one beautiful player

Designed with Material Design 3 and built with Tauri, so it stays small, quick and smooth.

Smart library

Scans your Videos folder automatically, remembers where you stopped and shows thumbnails in list or grid view.

Fast seeking

A built-in streaming server makes jumping around huge screen recordings instant instead of frozen.

Subtitles

SRT, VTT and ASS files are detected automatically, with adjustable delay, size, color and position.

Material You themes

Light, dark or system mode with a full Material color palette and your choice of fonts.

Full playback control

Speed 0.25–4×, A-B loop, frame stepping, volume boost, night mode, sleep timer and mini player.

Screenshots

Save or copy the current frame in one click, straight from the right-click menu.

English & Tiếng Việt

Picks the language of your device automatically and can be switched at any time.

Keyboard friendly

Shortcuts for everything, drag & drop for files and folders, and “Open with” integration.

Install

Up and running in a minute

  1. Download the installer using the button below.
  2. Run Material Video Player_1.0.0_x64-setup.exe and follow the wizard. If Windows SmartScreen appears, choose More info → Run anyway.
  3. Open the app — your Videos folder is scanned automatically. Drag & drop a video to start watching.
