# Download folder

Put the installer produced by `npm run build` here so the landing page download button works:

```
src-tauri/target/release/bundle/nsis/Material Menu_1.0.0_x64-setup.exe
        └── copy to →  download/Material Menu_1.0.0_x64-setup.exe
```

(With the shared workspace the build output lives in `<workspace>/target/release/bundle/nsis/`.)
