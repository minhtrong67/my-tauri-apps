{{icon:LayoutGrid}}Features

Everything you need to write great docs

A calm, fast workspace with the details that make Markdown a pleasure.

{{icon:Columns2}}

Live split preview

Write on the left and watch the preview update block by block, with synchronized scrolling and an outline that follows you.

{{icon:Command}}

Command palette

Press Ctrl+Shift+P to reach every action. Shortcuts cover the rest.

{{icon:ImagePlus}}

Paste images

Paste or drop an image and it is saved to an assets folder beside your file.

{{icon:Palette}}

Make it yours

18 Material colours, light, dark or system mode, three text sizes and seven fonts including Google Sans Flex, Roboto Flex and Be Vietnam Pro.

{{icon:Languages}}

English and Tiếng Việt

Switch the whole interface between two languages instantly.

{{icon:ShieldCheck}}

Never lose work

Autosave, restored sessions with unsaved drafts, and a prompt when a file changes on disk.

{{icon:LayoutTemplate}}

README helpers

Templates, badges, a table of contents and a formatting toolbar for faster docs.

{{icon:Zap}}

Light as a feather

Built with Tauri 2: a small installer that starts in a blink.
