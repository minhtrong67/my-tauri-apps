Features

Everything you need to make code look great

A focused toolbox with the details that matter — from pixel-perfect themes to one-click presets.

14 hand-tuned code themes

Dracula, Tokyo Night, Nord, Catppuccin, GitHub and more — with a live mini-preview right in the picker.

Gradient backdrops

Twelve gradients, custom colors and angles — or fully transparent.

Social-ready ratios

16:9, 4:5, 1:1, 9:16 and more, with auto-fit so code is never cropped.

Beautiful coding fonts

JetBrains Mono, Fira Code, Cascadia and 7 more — ligatures on or off.

Export anywhere

PNG, JPG or SVG at up to 4× resolution. Copy to the clipboard or save to a folder you choose, then reveal it in one click.

Presets

Save your favorite look. Built-ins for X, LinkedIn, Instagram and README.

Diff & focus mode

Highlight lines, dim the rest, or show +/− diffs in green and red.

Private by design

Everything runs locally. Your code never leaves your computer — no account, no tracking, no upload.
