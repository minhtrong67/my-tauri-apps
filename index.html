KIẾN TRÚC MONOREPO

Cargo Workspace: Tiết Kiệm Hơn 60 GB Bộ Nhớ

Thay vì 17 thư mục build Rust riêng biệt tốn kém hàng chục GB dung lượng đĩa, một Cargo Workspace duy nhất quản lý và chia sẻ toàn bộ cache biên dịch.

Cargo.toml (Root Workspace) 
[workspace]
resolver = "2"
members = ["*/src-tauri"]

[profile.dev]
debug = 0

[profile.release]
opt-level = "s"      # Optimize for size
lto = true            # Link-Time Optimization
codegen-units = 1     # Maximize LTO optimization
strip = true          # Strip all debug symbols
panic = "abort"       # Remove panic unwinding overhead

Bộ nhớ đệm biên dịch dùng chung (Shared target/)

Tất cả 17 ứng dụng biên dịch chung vào một thư mục ./target duy nhất ở gốc dự án, giúp chia sẻ triệt để các crate nặng như tauri, serde, tokio.

Tối ưu hoá kích thước nhị phân toàn cục

Cấu hình Link-Time Optimization (lto = true), strip debug symbols, và opt-level = "s" giúp tạo ra các tệp thực thi Windows nhỏ gọn đến khó tin.

Quy trình phát triển nhất quán

Chỉ cần một lệnh npm install và npm run tauri dev trong từng thư mục là có thể phát triển và kiểm thử độc lập mà không bị xung đột.

HƯỚNG DẪN

Dễ Dàng Sử Dụng & Phát Triển

Dù bạn là người dùng cuối muốn trải nghiệm ứng dụng hay lập trình viên muốn tham gia đóng góp.

01

1. Vào GitHub Releases

Truy cập trang Releases chính thức của kho mã nguồn trên GitHub để xem danh sách các phiên bản mới nhất.

02

2. Tải File Cài Đặt .exe

Lựa chọn ứng dụng bạn mong muốn và tải file cài đặt độc lập (.exe hoặc .msi) về máy tính của bạn.

03

3. Chạy Trực Tiếp & Trải Nghiệm

Mở file vừa tải để sử dụng ngay. Tương thích hoàn hảo với Windows 10 và Windows 11 mà không cần cấu hình phức tạp.

01

1. Clone Kho Mã Nguồn

Chạy lệnh: git clone https://github.com/minhtrong67/my-tauri-apps.git và chuyển vào thư mục dự án.

02

2. Cài Đặt Phụ Thuộc

Yêu cầu Node.js 18+ và Rust 1.77+. Chuyển vào thư mục ứng dụng bất kỳ (ví dụ: cd material-calculator) rồi chạy npm install.

03

3. Khởi Chạy Hot-Reload

Chạy npm run tauri dev để khởi động ứng dụng với chế độ tự động cập nhật mã nguồn (Hot Reload). Để build bản phát hành, chạy npm run tauri build.
