Features

Everything you need to ship a polished theme

More than a color picker: a full workbench for designing, checking and exporting Material 3 themes.

Dynamic color engine

Powered by Google's HCT color science. Choose from Tonal Spot, Vibrant, Expressive, Neutral, Monochrome, Fidelity, Content, Rainbow and Fruit Salad — and override any core palette.

Live component preview

Buttons, cards, inputs, navigation and more update instantly — in light, dark or side by side.

Accessibility built in

Color-blind simulation

FAQ

Questions, answered

Is it really free?
Yes. Material Theme Builder is open source under the MIT license — use it for personal and commercial projects.
Which platforms are supported?
The installer targets Windows 10/11. Because it is built with Tauri, you can also build it for macOS and Linux from source.
Are the colors identical to Google's Material Theme Builder?
It uses the same official material-color-utilities library, so schemes match the Material 3 specification. The app adds extras such as color-blind simulation, image extraction and more export formats.
Where are my themes stored?
Locally on your computer. Nothing is uploaded. You can export any theme as a project file and re-import it later.
How do I run it from source?
Run npm install, then npm run dev to develop and npm run build to create the installer. You need Node.js and the Rust toolchain.
How is it different from Google's Material Theme Builder?
Same official color science, different workflow. This app runs offline, imports existing themes, compares two themes side by side, extracts palettes from images, keeps version history and exports 10 formats. See the comparison table above.
Does it update itself?
Not automatically. Settings has a Check for updates button that looks for the newest GitHub release and opens its download page, so you stay in control of when to update.
