Features

Everything you need to juggle Claude accounts

Built for people who keep several Claude accounts in different Chrome profiles and just want to know who is free.

Live countdowns, to the minute

See exactly when each account resets, with the day, the clock time and a wavy progress bar. When a limit lapses the card celebrates with a little animation.

Usage forecast

Sparklines show your pace and predict when you will hit the limit.

Smart notifications

A warning before you run out, a note when it resets, and quiet hours.

One click to Chrome

Open the right profile — or the best available account — instantly.

Organize your way

Pin, rename, add notes, hide, search and filter. Grid or list view.

Private by design

Everything stays on 127.0.0.1. A token protects the local link and nothing is sent to any server.

Lives in your tray

Start with Windows, stay in the system tray, and see ready accounts at a glance on the tray tooltip.

How it works

Set up once, glance forever

Install the app

Download and run the installer. Claude Tracker opens with your connection port and token.

Add the extension

In every Chrome profile open chrome://extensions, enable Developer mode and load the bundled extension.

Paste port & token

Enter them once in the extension. Accounts appear on the dashboard automatically and keep syncing.

FAQ

Good to know

Is it really free and open source?

Yes. Claude Tracker is released under the MIT license and the full source code is public.

Does it send my data anywhere?

No. The extension talks only to the app on 127.0.0.1 using a private token. There are no servers and no telemetry.

Which browsers and systems are supported?

Windows 10 and 11 with Google Chrome profiles. The app is built with Tauri, so it is small and fast.

Are reset times exact?

Reset times come from Claude itself. Notifications are expected times: an account counts as recovered once the extension reports fresh data.

Windows warns about an unknown publisher. Why?

The installer is not code-signed yet. Choose “More info → Run anyway”, or build it yourself from the source.
