FAQ

Good to know

Is Material Edit really free?
Yes. It is open source under the MIT license — no watermark, no account, no subscription.
Which formats can I export?
MP4 (H.264 + AAC) is the default at up to 4K / 60 fps. WebM is available too, and MP4 via FFmpeg if you install it.
Are my media files copied or uploaded?
Never. Projects only remember the path to your files, and everything runs locally on your computer.
Does it work on macOS or Linux?
The project is built with Tauri and can be compiled for other systems with npm run build, but the official installer targets Windows.
How do I build it myself?
Install Node.js and Rust, then run npm install, npm run dev and npm run build inside the project folder.
